# Acer BIOS/UEFI and Boot Menu Keys

A guide to entering the BIOS setup, Boot Menu, and System Recovery on Acer computers.

## Primary Keys Summary

| Function | Primary Key | Alternative Keys |
| --- | --- | --- |
| **BIOS / UEFI Setup** | F2 | Del |
| **Boot Menu** | F12 | - |
| **System Recovery** | Alt + F10 | - |

## Acer Laptops (Aspire, Swift, Predator, Nitro, Spin, TravelMate)

### Modern Systems (2015 - Present)
* **BIOS / UEFI Setup:** Press **F2** repeatedly as soon as the Acer logo appears.
* **Boot Menu:** Press **F12** repeatedly at startup. 
  * *Note:* On many Acer laptops, the F12 Boot Menu is disabled by default. You must enter the BIOS (**F2**), go to the **Main** tab, enable **F12 Boot Menu**, save and exit.

### Legacy Systems (Pre-2015)
* **Older Aspire / TravelMate:** Press **F2** or **Del**.
* **Very Old Models:** Press **F1** or **Ctrl + Alt + Esc**.

## Acer Desktops (Aspire Desktop, Predator Desktop, Veriton)

* **BIOS / UEFI Setup:** Press **Del** or **F2** repeatedly at boot.
* **Boot Menu:** Press **F12** repeatedly at boot.

## Additional Acer Shortcuts
* **Acer eRecovery Management:** Press and hold **Alt + F10** at startup to launch the recovery partition.

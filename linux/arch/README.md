# arch-4-think<br>
This repository contains my tyical Arch Linux installation and package setup for university, personal projects and coding. <br>
It also contains several different Arch Linux instruction sets and manuals for things and processes frequently used when setting up or running a Arch Linux Setup. 

I have successfully used these settings on several devices:

- Lenovo ThinkPad T14 Gen. 2 (Intel)
- Lenovo ThinkPad X13 Yoga Gen. 2 (Intel)
- Lenovo ThinkPad X390 Yoga (Intel)
- Lenovo Thinkpad X230 (Intel)
- Lenovo ThinkPad T430 (Intel, no Nvidia GPU)
- HP EliteBook 840 G3 (Intel)
- HP ProBook 850 G8 (Intel)

In case you use a ThinkPad T430 with an Intel CPU und dedicated Nvidia GPU I recommend a different setup to utilize the Nvidia GPU.

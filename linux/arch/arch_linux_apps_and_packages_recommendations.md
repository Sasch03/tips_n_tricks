# Packages and Applications<br>
These are the packages and apps I installed on my machines. I do not use all of them frequently but keep them around as I deem them useful. 

Consider these as suggestions. Explanations what these apps do will not be provided however research in advance of an installation is strongly recommended. 

__PLEASE DO NOT INSTALL PACKAGES YOU DO NOT KNOW THEIR PURPOSE OR ORIGIN OF.__<br>
__CHECK WHETHER THESE PACKAGES ARE STILL SUPPORTED BEFORE INSTALLING.__

## Office Packages<br>
Packages I install via `pacman`:

```
sudo pacman -S libreoffice-fresh okular
```


## Services Packages<br>
Packages I install via `pacman`:

```
sudo pacman -S ark filelight kcalc spectacle terminator
```

Packages I install via `yay`:

```
yay -S balena-etcher
```

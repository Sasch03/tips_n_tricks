# Firmware Updates

To do firmware updates on your device, install the fwupd package:

```
sudo pacman -S fwupd
```

Follow the instructions to update your device firmware from the [fwupd](https://wiki.archlinux.org/title/Fwupd) page in the Arch Wiki.

It is recommended to restart your device after updating firmware to ensure a successful setup and to isolate possible occuring issues (never had any myself so far).
